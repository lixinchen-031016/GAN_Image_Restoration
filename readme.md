# 基于训练双任务判别器的生成对抗网络图像修复方法研究

## 摘要
本文提出了一种改进的生成对抗网络（GAN）架构，通过引入双任务判别器和动态训练策略，实现了高质量的图像修复。生成器采用多尺度残差结构结合注意力机制，判别器同时执行图像真实性判断和细粒度分类任务。实验表明，该方法在CIFAR-100数据集上取得了PSNR 30.78 dB和SSIM 0.9564的修复效果，相比基线模型提升较高。本研究创新性地提出了自注意力机制与空洞卷积的协同架构，并设计了可学习的标签平滑调度策略，显著提升了模型训练稳定性。

**关键词**：图像修复，生成对抗网络，双任务判别器，动态标签平滑，多尺度注意力

## 2. 方法论

### 2.1 网络总体架构
本研究采用了生成对抗网络的基本框架，包含生成器和判别器两个核心组件。生成器负责从带遮罩的输入图像中重建缺失区域，判别器则同时执行真假判断和细粒度分类任务。这种双任务设计使判别器能够更全面地理解图像内容，从而引导生成器产生更符合语义的修复结果。

为了提升模型性能，我们在架构中引入了多项关键技术：
1. **多尺度特征提取**：通过不同感受野的卷积核组合，捕获图像的多层次细节。
2. **注意力机制**：利用自注意力模块增强长距离依赖建模能力。
3. **空洞卷积**：扩大感受野而不增加参数量，保留更多空间信息。
4. **动态训练策略**：包括学习率调度和标签平滑技术，提升训练稳定性和收敛速度。

这些技术的选择基于对图像修复任务特点的深入分析：既要保证局部细节的真实性，又要保持全局结构的一致性；既要快速收敛，又要避免模式崩溃等常见问题。

### 2.2 生成器设计
生成器网络采用双路径架构：

#### 2.2.1 图像特征路径
图像特征路径由初始卷积层和三级残差下采样模块构成。初始卷积层使用5×5卷积核提取基础特征，随后的每级下采样模块包含：
- 卷积层：3×3卷积核，步长2，实现空间维度减半
- 批归一化层：加速训练并稳定分布
- Swish激活函数：相比ReLU提供更好的非线性表达能力
- 残差连接：缓解梯度消失问题，保留细节信息

数学表示如下：
$$\begin{aligned}
x_{down}^{(i)} &= Conv_{3×3}(x^{(i-1)}) \\
x_{res}^{(i)} &= Conv_{1×1}(x_{down}^{(i)}) + Conv_{3×3}^2(x_{down}^{(i)})
\end{aligned}$$

这种设计的优势在于：
1. 多级下采样逐步提取深层特征
2. 残差连接确保梯度有效传播
3. Swish激活函数提升非线性表达能力
4. 适当深度平衡计算效率和表达能力

#### 2.2.2 遮罩处理路径
遮罩处理路径独立处理遮罩信息，包含三级下采样模块：
- 初始卷积层：5×5卷积核提取遮罩特征
- 三级下采样：3×3卷积核，逐步降低空间维度
- 最终特征尺寸：4×4×64
- 空间Dropout率：0.3，防止过拟合

这种设计使模型能够：
1. 独立学习遮罩位置的空间关系
2. 与图像特征路径并行处理不同模态信息
3. 保持遮罩特征的高分辨率表示

#### 2.2.3 特征融合与上采样
特征融合阶段将图像特征路径和遮罩路径的输出进行通道拼接：
$$F_{combined} = [F_{image}^{(512)}; F_{mask}^{(64)}] \in \mathbb{R}^{4×4×576}$$

随后通过三级上采样重构图像：
1. 上采样层：2×2倍数放大
2. 卷积层：3×3卷积核，调整通道数
3. 批归一化层：稳定训练过程
4. Swish激活函数：增强非线性表达

数学表示如下：
$$\begin{aligned}
F_{up}^{(1)} &= Upsample_{2×}(Conv_{3×3}^{512}(F_{combined})) \\
F_{up}^{(2)} &= Upsample_{2×}(Conv_{3×3}^{256}(F_{up}^{(1)})) \\
F_{up}^{(3)} &= Upsample_{2×}(Conv_{3×3}^{128}(F_{up}^{(2)}))
\end{aligned}$$

这种设计的优势在于：
1. 逐步恢复空间分辨率
2. 保持特征传递的连续性
3. 适当控制参数量增长

#### 2.2.4 注意力增强模块
注意力增强模块包含三种机制：
1. **空间自注意力**：计算特征图位置间的相关性
   $$Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$
   其中通道缩减比$r=4$，可学习参数$\gamma$初始为0，动态调整注意力强度：
   $$Output = (1-\gamma)\cdot x + \gamma\cdot AttendedFeature$$

2. **SE注意力**：通道注意力权重计算：
   $$\alpha_c = \sigma(MLP(GAP(x)))$$

3. **残差注意力块**：级联两个卷积层+自注意力
   - 包含两个残差注意力块
   - 每个块包含卷积堆叠和注意力增强

这些注意力机制的引入使得模型能够：
1. 动态关注重要特征区域
2. 增强长距离依赖建模能力
3. 提升特征表示的有效性
4. 缓解梯度消失问题

### 2.3 判别器设计
判别器网络包含4级下采样模块：

#### 2.3.1 特征提取层
特征提取层包含四级卷积模块：
1. 输入层：32×32×3 RGB图像
2. 卷积块1：5×5卷积核，步长2，64通道 → 输出16×16
3. 卷积块2：3×3卷积核，步长2，128通道 → 输出8×8
4. 卷积块3：3×3卷积核，步长2，256通道 → 输出4×4
5. 卷积块4：3×3卷积核，步长2，512通道 → 输出2×2

每个卷积块包含：
- 卷积层：提取特征
- 批归一化层：稳定训练过程
- LeakyReLU激活函数：缓解神经元死亡问题
- Dropout层：防止过拟合

这种设计的优势在于：
1. 渐进式提取多尺度特征
2. 足够的深度捕捉复杂模式
3. 合理的参数量控制计算成本

#### 2.3.2 自注意力模块
改进的自注意力模块具有以下特点：
- 通道缩减比改为4，平衡计算效率和表达能力
- 可学习的缩放参数$\gamma$初始为0，逐步增加注意力影响
- 动态reshape处理空间维度，适应不同分辨率特征图

数学表示如下：
$$\begin{aligned}
q &= Conv_{1×1}(x) \\
k &= Conv_{1×1}(x) \\
v &= Conv_{1×1}(x) \\
attention &= softmax(\frac{qk^T}{\sqrt{d_k}})v \\
output &= (1-\gamma)\cdot x + \gamma\cdot attention
\end{aligned}$$

这种设计的优势在于：
1. 减少计算量的同时保持表达能力
2. 可学习参数控制注意力强度
3. 动态调节注意力机制的影响

#### 2.3.3 多尺度特征融合
多尺度特征融合包含三个分支：
1. 全局平均池化：提取整体特征 $F_{global} \in \mathbb{R}^{512}$
2. 2×2池化：保留局部结构信息 $F_{local} \in \mathbb{R}^{1×1×512}$
3. 1×1池化：保留原始空间信息 $F_{detail} \in \mathbb{R}^{2×2×512}$

最终特征拼接：
$$F_{concat} = [F_{global}; F_{local}; F_{detail}] \in \mathbb{R}^{3072}$$

这种设计的优势在于：
1. 捕获不同粒度的信息
2. 增强特征表示的丰富性
3. 提升判别能力

#### 2.3.4 双任务输出层
双任务输出层包含两个分支：
1. **真实性分支**：
   - 结构：3072→256→128→1
   - 激活函数：sigmoid
   - 目标：判断图像是否为真实样本

2. **分类分支**：
   - 结构：3072→512→256→100
   - 激活函数：softmax
   - 目标：预测图像所属类别

这种设计的优势在于：
1. 强制判别器理解图像语义内容
2. 提供额外监督信号提升训练稳定性
3. 促进生成器生成更符合语义的修复结果

### 2.4 损失函数
总损失函数包含四个分量：

$$\begin{aligned}
\mathcal{L}_{total} &= \mathcal{L}_{adv} + 0.5\mathcal{L}_{cls} + 0.1\mathcal{L}_{rec} + 10\mathcal{L}_{gp} \\
\mathcal{L}_{adv} &= \mathbb{E}[\log D_{valid}(G(I))] \\
\mathcal{L}_{cls} &= \mathbb{E}[\mathcal{H}(y_{fake}, D_{cls}(G(I)))] \\
\mathcal{L}_{rec} &= \|G(I) - I_{original}\|_1 \\
\mathcal{L}_{gp} &= \mathbb{E}[(\|\nabla_{\hat{x}}D(\hat{x})\|_2 - 1)^2]
\end{aligned}$$

其中各分量的作用：
1. $\mathcal{L}_{adv}$：对抗损失，推动生成器生成逼真图像
2. $\mathcal{L}_{cls}$：分类损失，促使生成器生成符合特定类别的图像
3. $\mathcal{L}_{rec}$：重建损失，保证局部细节的真实性
4. $\mathcal{L}_{gp}$：梯度惩罚项，约束判别器的Lipschitz常数

权重设置依据：
- $\lambda_{gp}=10$：较大的梯度惩罚系数确保训练稳定性
- $\lambda_{cls}=0.5$：适中的分类损失权重平衡两种任务
- $\lambda_{rec}=0.1$：较小的重建损失保持主要优化方向

### 2.5 动态训练策略

#### 2.5.1 标签平滑调度
标签平滑技术用于缓解判别器过度自信的问题，其调度公式为：
$$\alpha_t = \alpha_{min} + \frac{1}{2}(\alpha_{max}-\alpha_{min})(1+\cos(\pi t/T))$$

具体参数设置：
- $\alpha_{min}=0.01$：最小平滑系数，防止标签完全模糊
- $\alpha_{max}=0.2$：最大平滑系数，在训练初期提供更强正则化
- 预热周期$T_{warm}=100$ epoch：逐步增加平滑程度

这种调度策略的优势：
1. 训练初期较大的平滑系数防止判别器过早饱和
2. 后期逐渐减小平滑系数提高判别精度
3. 余弦衰减曲线保证平滑过渡

#### 2.5.2 学习率调度
学习率调度采用预热加余弦退火的组合策略：

$$lr_t = \begin{cases}
lr_{min} + \frac{t}{T_{warm}}(lr_{max}-lr_{min}), & t < T_{warm} \\
lr_{min} + \frac{1}{2}(lr_{max}-lr_{min})(1+\cos(\pi (t-T_{warm})/T)), & t \geq T_{warm}
\end{cases}$$

具体参数设置：
- $lr_{max}=1e-4$：初始较大学习率加快收敛
- $lr_{min}=1e-5$：最终较小学习率精调参数
- 总训练周期$T=1500$

这种调度策略的优势：
1. 预热阶段逐步增加学习率，避免初始化不稳定
2. 余弦退火阶段平滑降低学习率，提高收敛质量
3. 整体调度兼顾训练速度和最终性能

#### 2.5.3 优化器配置
优化器配置根据任务特点进行专门设计：
- **生成器优化器**：
  - Adam优化器
  - 学习率：1e-4
  - 动量参数：$\beta_1=0.5, \beta_2=0.9$
  - 梯度裁剪阈值：1.0

- **判别器优化器**：
  - Adam优化器
  - 学习率：5e-5（生成器的一半）
  - 动量参数：$\beta_1=0.5, \beta_2=0.999$
  - 梯度裁剪阈值：1.0

这种配置的优势：
1. 不同学习率比例平衡生成器和判别器的更新速度
2. 不同动量参数适应两类网络的更新特性
3. 梯度裁剪防止爆炸，提高训练稳定性

## 3. 实验分析

### 3.1 数据集处理
实验使用CIFAR-100数据集，处理流程如下：

1. **数据归一化**：
   $$I \in [0,1]^{32×32×3}$$
   将像素值缩放到[0,1]区间，便于网络处理

2. **随机矩形遮罩**：
   - 遮罩尺寸：8×8像素
   - 随机位置：$top \sim U(0,24),\ left \sim U(0,24)$
   - 遮罩方式：将指定区域像素置零

这些处理的优势：
1. 归一化统一数据分布
2. 随机遮罩模拟多种损坏情况

### 3.2 实现细节
实现细节包括：
- 批大小：256
- 训练轮数：1000
- 模型保存间隔：100轮
- 最佳模型保存：800轮后当验证损失降低时
- 硬件配置：Apple M1芯片
- 单epoch训练时间：约2.5秒

这些选择基于：
1. 批大小平衡内存占用和训练效率
2. 足够的训练轮数确保充分收敛
3. Apple M1提供高效的Metal加速支持
4. 定期保存模型便于结果分析

### 3.3 结果分析
定量评估结果如下：

| 评估指标       | 训练集    | 测试集    |
|----------------|--------|--------|
| PSNR (dB)      | 32.15  | 30.78  |
| SSIM           | 0.9621 | 0.9564 |
| 分类准确率      | 92.3%  | 89.7%  |

定性分析显示：
1. 修复结果在视觉上难以区分真假
2. 边缘和纹理细节保持良好一致性
3. 对大范围遮罩仍能保持合理结构
4. 在复杂背景场景表现尤为突出

对比基线模型：
1. PSNR提升约2.5 dB
2. SSIM提升约0.03
3. 训练稳定性显著提高
4. 收敛速度加快约30%

这些结果证明了所提方法的有效性：
1. 多尺度注意力机制显著提升修复质量
2. 动态标签平滑改善训练稳定性
3. 双任务判别器增强语义理解能力
4. 整体架构设计达到先进水平
